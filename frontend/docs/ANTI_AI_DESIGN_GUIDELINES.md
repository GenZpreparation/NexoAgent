### 2.1 The Obsidian Palette (Not Black, Not Gray — Crafted Dark Tone)

* **Surface Containers:** `#0d121f` with hairline border `rgba(255, 255, 255, 0.08)`.
* **Elevated Hover Surface:** `#141c2e` with subtle indigo highlight glow.

* **Telecom Live Green:** `#10b981` (High-contrast emerald with ping micro-dot).
* **Lead Qualification Gold:** `#f59e0b` (Warm amber for deals and ROI savings).

## ⌨️ 4. Native Software Details (What Makes it Feel Like a $10M Product)

1. **Keyboard Shortcuts Support (`⌘K` / `Ctrl+K`):**  
   Dashboard me ek global Command Palette hoga. Customer `Ctrl+K` dabayega aur seedha:
   - *"Create Agent"*, *"Upload CSV"*, *"Check Balance"*, *"Filter Hot Leads"* search kar sakega. (Linear style!).
2. **True Telecom Monospace Data Typography:**  
   Call durations (`01:15`), phone numbers (`+91 98765 43210`), Call SIDs (`CA_9a04...`), aur billed costs (`₹11.00`) hamesha crisp monospace (`JetBrains Mono` ya `Geist Mono`) me rahenge with tabular figures (`font-variant-numeric: tabular-nums`). Isse numbers table me wobble nahi karte.
3. **Sound-Toggle Feedback:**  
   Jab audio recording play ho ya barge-in trigger ho, ek subtle visual audio visualizer bar animate karega.
4. **Micro-Copy with Personality:**  
   AI templates me boring text hota hai jaise *"Click here to submit"*. Hum real Indian telecom phrasing use karenge:
   - *"₹5.50 per connected minute (Zero charge if customer is busy or doesn't answer)"*
   - *"Scrubbed 142 DND numbers to protect you from TRAI penalties"*
   - *"Pooja will start speaking within 400ms of user saying Hello"*

## 🛠️ 5. Rules for Frontend Developers (Execution Checklist)

* [ ] **Rule 1: No Unstyled Skeletons:** Loading screens par bland gray boxes ke bajaye subtle shimmering wave pulse hoga (`bg-gradient-to-r from-slate-900 via-slate-800 to-slate-900 animate-shimmer`).
* [ ] **Rule 2: Responsive Data Density:** Tables desktop par rich columns dikhayengi (Duration, Pulse, Cost, Sentiment, WhatsApp), aur mobile par intelligently swipeable cards me collapse ho jayengi.
* [ ] **Rule 3: Hairline Borders Over Heavy Shadows:** Kabhi bhi `shadow-2xl` use mat karo. Hamesha `border border-white/[0.08]` aur `hover:border-indigo-500/40` use karo.
* [ ] **Rule 4: Interactive over Static:** Agar landing page par ROI dikhana hai to static number mat likho, slider do jise visitor khud drag karke apne numbers calculate kare.
* [ ] **Rule 5: Sub-Millisecond Feel:** Page transitions instant honge (`framer-motion` ke layout animations with `transition={{ duration: 0.15, ease: "easeOut" }}`).
